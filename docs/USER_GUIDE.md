# Sili-Tubig: Quiz Avenue — User Guide

## Install
- **Android:** copy `SiliTubig_QuizAvenue.apk` to your phone, open it, and allow
  "install unknown apps" if asked. Hold the phone sideways.
- **PC:** open the project folder in Godot 4.7 and press F5.

## Start
1. Tap the name card at the top left of the title screen to set your name (up to 12 letters).
2. Press **PLAY**:
   - **SOLO VS BOT:** you are the Tubig. 4 rounds from Easy to Labuyo (1–3 bots). Your round is saved; past Round 1 you are asked RESUME or NEW GAME.
   - **HOST GAME:** start a LAN game; your IP is shown on the chalkboard.
   - **JOIN GAME:** tap JOIN next to a game, or type the host's IP.
   Everyone must be on the same Wi-Fi or phone hotspot.

## Roles
- 2 players: both are Tubig and a **bot Sili** chases you. 3–4 players: 1 Sili. 5–6 players: 2 Silis.
- Before every round you see your role and a 3-2-1-GO countdown.

## Goal
- **Tubig:** answer the goal number of questions ("?" scrolls) before time runs out.
- **Sili:** freeze every Tubig at the same time, or survive until time runs out.

## Controls

| Action | Keyboard | Phone |
|---|---|---|
| Move | W A S D / arrows | Drag on the right half of the screen (left half with the swapped layout) |
| Sprint | Shift / Space | Hold RUN (bottom left, or bottom right with the swapped layout) |
| Use a power-up station | E | Tap USE (appears next to a station) |
| Answer | A B C D (1–4 also work) or click | Tap |
| Ask a teammate for help | H | Tap the button |
| Pause menu (settings, help, leave) | Esc | Pause button (top right) or Back |
| Leave the game | Pause menu → LEAVE → LEAVE GAME? → LEAVE | Pause menu → LEAVE → LEAVE GAME? → LEAVE |

## The screen
- **Top left:** the scroll icon and your questions (for example `0/6`), then every
  Tubig's name with **3 hearts**.
- **Top centre:** the round (for example `Easy vs 1 Bot`) and the time left.
- **Top right:** the MAPA and the **pause button**.

## Pause menu
Tap the pause button (or press Esc / Back). The SETTINGS window opens with **HELP**
(How to Play) and **LEAVE**. In solo, and for the LAN host, the round pauses until you
close the window (✕, Esc, or tap outside). When the host pauses, everyone else sees the
same window with settings and HELP only.

## Leaving
- **Solo:** leave any time (pause menu → LEAVE → LEAVE).
- **LAN host:** you can leave any time, but it **ends the game for everyone**.
- **LAN players:** the LEAVE button appears when the round is over. If the host leaves,
  you see "GAME OVER — THE HOST LEFT" and can go back to the main menu.

## Power-ups (new spots every round)
- **Halo-Halo coolers** (Tubig): Yelo Shield for 10 s. A Sili who tags you is extinguished.
- **Bicol Express peppers** (Sili): solve a bugtong for Extra Anghang (faster, wider reach).
- **Kalamansi gates** (anyone): answer to squeeze through a shortcut; a wrong answer slows you.

## Frozen?
A teammate touches you and answers a question (**Buhos-Tubig**). If nobody can help, answer
2 hard questions in a row to thaw yourself (**Huling Hirit**).

**Hearts:** every Tubig has 3. Each freeze costs one, even if you are saved, and your hearts
turn icy blue while you are frozen. Frozen with your last heart = **OUT**: nobody can save
you for the rest of the round. In solo that ends the round.

## Settings (gear button on the title screen, pause menu in the game)
Music and sound volume, touch controls, **Layout** (phones: RUN / USE left + joystick right,
or joystick left + RUN / USE right), vibration (phones and tablets), Show FPS, and
**Reset my data** (tap twice; not during a round), which clears your name, settings, solo
progress and this phone's leaderboard.

## Troubleshooting
- **Can't find the game in JOIN:** use a phone hotspot; type the IP shown in the host's window.
- **"Could not connect":** check that both devices are on the same network and the IP is right.
- **"The leaderboard file was damaged or edited":** the board was reset to protect it.
